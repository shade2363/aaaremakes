What we build

A pipeline, not a port.

A conversion is thousands of small decisions made consistently. We build tooling that makes those decisions the same way every time — so a world stays coherent from the first mesh to the last quest stage.

  1. 01

    Ingest & map

    Read the source plugins, archives and scripts. Map records, form types and references onto the target schema before a single asset moves.

    • ESM parsing
    • Form mapping
    • Archive unpack
  2. 02

    Translate assets

    Meshes, materials, textures and audio rebuilt for the new renderer — correct scale, correct shaders, correct collision.

    • Mesh rebuild
    • Physics
    • Materials
  3. 03

    Rebuild systems

    Navmesh, AI packages, factions, inventories and quest logic re-authored in the target language and verified against the original behaviour.

    • Navmesh
    • AI & factions
    • Quests
  4. 04

    Validate & ship

    Automated record checks, playthrough passes and performance budgets. Anything that fails is a bug in the pipeline, not a chore for the player.

    • Record QA
    • Playtests
    • Perf budget

The studio

Small studio. Long pipelines.

AAARemakes is an independent conversion studio. We take old games seriously: their pacing, their jank, their intent. A remake that plays like a different game isn't a conversion.

We work in the open about what's done and what isn't. No trailer built from a render, no percentage that means nothing. If a system is running in a playable build, it's on this site.

  • 01

    Behaviour over fidelity

    The original game has to still feel like itself. When fidelity and feel conflict, feel wins.

  • 02

    Tooling first

    A fix done by hand is a fix that comes back. Every manual step becomes a pipeline stage.

  • 03

    Respect the rights holders

    We ship pipeline work and documentation — never somebody else's assets.

Questions

The short answers.

Is a conversion build downloadable?

Fallout 4-Ever FO3 is: it's a free installer on GitHub. It builds from your own copies of Fallout 3 and Fallout 4, ships no game files, and the result is for personal use only. The New Vegas and Skyrim editions aren't public yet.

What's missing from the Fallout 4-Ever demo?

Quests, dialogue, voice, music, radio and NPC faces. What's in it: the whole Capital Wasteland and the five DLC worlds, 4,260 placed actors, 7,198 navmeshes, rebuilt lighting and water, and a New Game start outside Vault 101. The repository's roadmap tracks what lands next.

Why does the first conversion take 4–8 hours?

It's re-authoring a world, not copying one: thousands of records, meshes and references are translated and rebuilt on your machine. It runs unattended and resumes where it stopped, so you can close the window and come back.

Why the Fallout 4 engine and not something newer?

It's the closest relative to the source games. Records, scripting model and asset formats are near enough that a principled conversion is possible — which is exactly what makes the pipeline generalise to the next title.

How long does a conversion take?

Longer than a port, shorter than a remake. The first pass on a title is the expensive one; subsequent titles reuse the mapping and tooling. We don't quote dates before a record map exists.

Do you take on outside projects?

Selectively. We're most useful to teams with a defined source game, a target engine, and a reason to stay inside the engine family. Get in touch with the specifics.

Can I follow the work?

The Discord server is the main room: announcements, roadmap talk and build reports. The GitHub repository carries releases and issues.

Where do I report a bug or ask for help?

The Discord is fastest — install reports, screenshots and crash logs go there first. Anything that needs tracking belongs in the GitHub issues as well.
